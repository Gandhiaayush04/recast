# Security

If you find a security issue in Recast, please don't open a public issue. Report it privately through GitHub instead: go to the **Security** tab of this repo and click **Report a vulnerability**.

Please include what you found, the steps or a sample file to reproduce it, and which version of Recast and macOS you're on. I'll get back to you as soon as I can and credit you in the fix if you'd like.

## What Recast is designed to do

- Run completely offline. Recast itself never makes network requests.
- Only read the files you give it and only write to the folder you choose (Downloads by default).
- Refuse files that try to pull in content from other places on your Mac or the internet.
- Stop oversized or malformed files before they use up your Mac's memory.

If you find a way around any of these, that's exactly what I want to hear about.
